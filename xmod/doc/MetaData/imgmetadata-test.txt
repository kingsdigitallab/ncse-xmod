possible separators
_=;|


-----------

- we expected only the lowest hierarchy level to be entered into the
  image metadata field
- but instead the whole hierarchy (all levels) are entered - this is
  not really a problem, but the separator used to separate the level
  is a forward slash ("/"), which appears quite often within the
  hierarchy terms - we therefore suggest that an underscore "_" is
  used
- we would also strongly suggest to "turn off" the possibility to
  insert new entries into the hierarchy master file (XML file) - it is
  too easy to completely "mess up" the XML hierarchy file - we suggest
  that additional entries into the hierarchy file should be made into
  the spreadsheet, and we insert them into the XML file
- another oddity: newly entered hierarchy terms are converted to
  uppercase by the Content Administrator
