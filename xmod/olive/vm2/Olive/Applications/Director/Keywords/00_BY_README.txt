
imagedescription.xml
--------------------

NCSE added values should be indicated with "ncse", so that an 
addition of "the mountains" as a natural environment would be given
the id:

<L3>the mountains id:ncse:d9z9999</L3>

For ease of addition, new ids can be added in sequentially descending
order, i.e. d9z9999, d9z9998, d9z9997.
